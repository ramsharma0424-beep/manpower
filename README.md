# Rudra Manpower Services

Company website for **Rudra Manpower Services Pvt. Ltd.** — security, housekeeping, and manpower solutions across Delhi NCR.

## Tech stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Pages

- Home, About, Services, Clients, Blogs, Contact
- Privacy, Terms, Cookie Policy, Disclaimer
